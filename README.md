# Python Projects

A collection of beginner-friendly Python projects and practice scripts.

## Projects

- `basic/first_test.py` - a simple starter script for basic Python practice.
- `basic/projects/dice_game.py` - a turn-based dice game where players race to 30 points.

## Run

```bash
python basic/first_test.py
python basic/projects/dice_game.py
```

## Goal

This repo is for learning Python by building small hands-on projects.
